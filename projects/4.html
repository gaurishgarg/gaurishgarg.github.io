WOW! Wizard on Watch in VR

User Profile

"As an XR user, I find it difficult to remember mid-air interactions. It would be nice to have a handy, all-in-one interface for interactions in VR"

Problem Statement

For various VR tasks, we rely on different interactions, be it raycast or pinch to select. However, in complex interaction scenarios, combination of different interactions adds cognitive load, making interaction difficult

Design Challenge

How can we design an interface that provides a handy all-in-one interface for interaction in VR

Target Platform

Goal Statement

Developing a User Interface that provides interactive cues for quick interactions

Scope

Design of an intuitive user interface for interaction in VR

Concept

A wearable touchpad pooping out of user's virtual wristwatch
